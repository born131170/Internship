# PersonaScope — запуск на Windows

Анализ личности по видео: MediaPipe (локальный движок) + LLM (внешний API).

## Важно про вашу ошибку

Ошибка `libEGL.so.1 ... apt-get` возникала из-за старой версии кода, которая
проверяла Linux-библиотеки даже на Windows. **На Windows эти библиотеки не нужны
и не существуют** — их нельзя и не нужно ставить. В актуальном коде проверка
сделана кросс-платформенной.

Команда `apt-get` — это пакетный менеджер Linux, в `cmd.exe` она не работает.

## Вариант 1 (рекомендую): скачайте ZIP заново

Вы скачали архив **до** того, как фикс попал в репозиторий. Проще всего получить
свежую версию:

1. Откройте страницу репозитория на GitHub.
2. Зелёная кнопка **Code** → **Download ZIP**.
   (Скачивайте именно со страницы ветки `main`/дефолтной, после последнего коммита.)
3. Распакуйте архив в новую папку, например
   `C:\PersonaScope` (в пути лучше избегать кириллицы и пробелов).
4. Откройте `cmd.exe`, перейдите в папку и запустите (см. «Запуск» ниже).

## Вариант 2: git pull (если у вас клонированный репозиторий)

Откройте **Git Bash** или обычный `cmd.exe` (нужен установленный Git):

```bat
cd "C:\Users\Nikolaev.A\Desktop\password\Университет\Стажировка\0002\Internship-main (1)\Internship-main"
git remote -v        :: должен показать ваш репозиторий на github.com
git pull             :: подтянет последние коммиты с GitHub
python run.py
```

Если `git pull` ругается на локальные изменения: `git stash && git pull`.

## Запуск (после получения свежего кода)

```bat
cd C:\PersonaScope
python run.py
```

`run.py` сам:
- проверит Python-зависимости и при нехватке выполнит `pip install -r requirements.txt`;
- на Windows **не** трогает OpenGL-библиотеки (они не нужны);
- поднимет сервер и напишет адрес, обычно http://127.0.0.1:8001

Ручная подготовка окружения (если автоустановка не сработала):

```bat
py -3.11 -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
python run.py
```

Требования: Windows x64, Python 3.9–3.12 (mediapipe не собирается на 3.13 —
если у вас 3.13, поставьте рядом 3.11/3.12 и запускайте через него),
Microsoft Visual C++ Redistributable 2015-2022 (x64).

## Если снова выскочит ошибка про apt-get/libEGL

Значит, код всё ещё старый. Проверьте:

```bat
findstr /C:"Windows" pipeline.py
```

В свежей версии в `pipeline.py` есть функция `ensure_mediapipe_gl()` с веткой
`if system != "Linux":` — на Windows она только делает smoke-тест импорта
mediapipe и никогда не предлагает apt-get.

## Настройка LLM

Ключ внешнего API задаётся в интерфейсе (вкладка настроек) или в файле `.env.local`
(не коммитить!). Локальный движок MediaPipe работает без интернета.
